## Project Structure

This repository is organized to show the full source code and build assets:
*   **Root Directory:** Contains the core source code (`main.js`, `preload.js`, `package.json`).
*   **`build/` Folder:** Contains the pre-compiled binaries and resources for the Windows client.

## Key Features

*   **Uncapped FPS:** Experience smoother gameplay with an uncapped frame rate. The client utilizes specialized performance flags and overrides `requestAnimationFrame` to bypass standard browser limitations.
*   **Performance Optimized:** Built with efficiency in mind to ensure low latency and high responsiveness during intense matches.
*   **Transparency:** Full source code is available for inspection and community verification.

## Installation

1. **Download:** Get the latest pre-built version from the [Releases](https://github.com/undon995/survev-client/releases) page.
2. **Extract:** Unzip the files to your preferred directory.
3. **Run:** Execute `SurvevClient.exe` from the extracted folder.
