SURVEV.IO UNCAPPED FPS CLIENT
==============================

This package contains everything you need to create your own high-performance 
desktop client for survev.io with uncapped FPS.

QUICK START:
1. Make sure you have Node.js installed (https://nodejs.org/).
2. Double-click "build_client.bat".
3. Wait for the process to finish.
4. Your EXE will be in the "dist" folder.

FEATURES INCLUDED:
- FPS Uncap (overrides requestAnimationFrame)
- GPU Hardware Acceleration
- V-Sync Disabled
- High-performance timer enabled
- Portable EXE (no installation required)

FILES:
- main.js: App configuration and performance flags.
- preload.js: Injected script for the FPS uncap logic.
- package.json: Build settings.
- icon.png: Application icon.
- build_client.bat: One-click build script for Windows.
